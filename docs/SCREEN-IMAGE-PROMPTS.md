# SUPERDORO — 43 mobile image-generation briefs
**Status:** written prompts only, not 43 generated images. Each section describes ONE high-fidelity vertical native mobile UI screen. Use ChatGPT image generation for concepts and Paper MCP for editable review frames **only after a verified local Paper connection**, never treat images as working gestures.

## Universal prompt prefix (prepend to every request)
> Generate a **single** polished high-fidelity 393×852-pt-proportion SUPERDORO native mobile screen, no phone mockup shell or desktop UI. Match the user's approved geometric angular S logo/wordmark where a real master is provided; if absent use a clearly replaceable approximation rather than distort the identity. Premium warm-white and charcoal-dark visual system, soft mint-green accent glow selectively, 8-point spacing rhythm, 16–24dp inset, minimum practical 44–48dp touch targets, correct safe areas and home indicator, keyboard-safe sticky actions, clean bold contemporary sans, realistic information density and high contrast. Preserve components/nav and label styles across the entire set. This is a representative *still frame* of an interaction specified by the matching ID in DETAILED-SCREEN-MOTION-UX.md; don't render movement or fake real data, and avoid overbright neon/glass effects. No multi-phone grid and no fictional live service status.

For dark screenshots, use glass charcoal raised surfaces; for light, white/off-white airy cards. The screenshot should communicate a meaningful action or its current content state with correct UX hierarchy. Keep all content within one realistic phone viewport; below-fold material may scroll in the real app but isn't crammed into the image.

## Priority anchors
1. **NOTE-02**: rich note detail — the content, reading hierarchy and contextual actions foundation.
2. **WEB-02**: search results sheet — correct in-context secondary overlay and 3–5 attachable source results.
3. **FOCUS-02**: light/dark precision timer — white/bright circular ring with interior ticks, calm interaction.
